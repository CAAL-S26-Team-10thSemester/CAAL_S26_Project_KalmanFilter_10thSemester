Kalman Filter: Milestone-3
RISC-V Scalar Assembly Implementation
Deadline: 13th April
1 Purpose of this Milestone
Milestone 3 marks the transition from high-level C/C++ implementation to low-level RISC-
V scalar assembly programming. Building directly on the LKF and EKF implementations
from Milestone 2, students will re-implement the core computational functions of both filters
inRISC-V scalar assembly.
This milestone develops a fundamental understanding of how abstract mathematical op-
erations — matrix multiplications, LU decompositions, Jacobian evaluations — map onto
actual processor instructions, register files, memory hierarchies, and calling conventions.
2 Background: RISC-V Architecture Recap
2.1 Registers
RISC-V provides 32 integer registers (x0–x31) and 32 floating-point registers (f0–f31). Ta-
ble 1 summarises the names and their roles.

4 Problem Description
Using the same 23-joint full-body gait dataset from Milestone 2, students must re-implement
the following computational components entirely in RISC-V scalar assembly:
1. Core equations of LKF and EKF.
2. Matrix Inverse technique (same as used in Milestone-2).
3. Algorithm used to calculate arctan.
4. Memory management (stack/heap).
